## Consuming this feed

This repo publishes two machine-readable files, regenerated on every run:

- `feed.json` — flat JSON array, easiest for a script or agent to parse
- `feed.xml` — standard RSS 2.0, works with any feed reader

If this repo is public, both are reachable without auth at:
```
https://raw.githubusercontent.com/<your-username>/<your-repo>/main/feed.json
https://raw.githubusercontent.com/<your-username>/<your-repo>/main/feed.xml
```
